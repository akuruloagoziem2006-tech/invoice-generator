# Invoice Generator

A clean and simple invoice generator for freelancers and small businesses.

## Features
- Create professional invoices
- Add logo
- Multiple line items
- Tax calculation
- Currency selector
- Due date + payment status (Paid / Unpaid / Overdue)
- Auto invoice numbering
- Save and load invoices
- Print / Save as PDF
- Dark mode

## Live Demo
https://invoice-generator-lilac-five.vercel.app/

## Tech Stack
- Next.js
- React
- JavaScript
- LocalStorage

## Getting Started
```bash
npm install
npm run dev
